## 📦 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/harshsahu11/Harsh_Sahu_Portfolio.git
   cd Harsh_Sahu_Portfolio
   ```
2. **Install dependencies:**
   ```bash
   npm install
   ```
3. **Run the development server:**
   ```bash
   npm run dev
   ```
4. **Open in browser:**
   Visit [http://localhost:5173](http://localhost:5173)
